Coherent State Network Protocol (CSNP), and the canonical version 1.1.0

should be included in the citation record. Version 1.1.0 preserves the complete
nine-person citation team established for version 1.0.0.

This file is the concise citation-team index. The canonical detailed
contribution and provenance statements are maintained in
[`paper/CONTRIBUTIONS.md`](paper/CONTRIBUTIONS.md), while
[`CITATION.cff`](CITATION.cff) is the machine-readable author list. Changes to
names or ordering must be synchronized across all three records.

## Version 1.1.0 contribution emphasis

Version 1.1.0 formalizes selected post-v1.0 developments from Tassan's HAL
research record: signed temporal displacement, a four-stage semantic interaction
cycle, proposed multi-task braking, and externally reported threshold claims.
Slade translated those developments into the versioned formal state, protocol
variables, non-interference boundary, falsifiers, verifier-facing semantics, and
archival manuscript.

These statements are deliberately source-bounded. They do not imply that every
author wrote every line of the consolidated manuscript or implemented every
software component.
